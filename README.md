## Sobre o projeto

Programa desenvolvido em Python como parte das Atividades Práticas Supervisionadas (APS2), com o objetivo de demonstrar o funcionamento da Cifra de Vigenère e a importância das chaves na criptografia de mensagens.

O projeto utiliza um cenário acadêmico de comunicação controlada envolvendo uma embarcação com materiais tóxicos.

## Funcionalidades

- Criptografia e descriptografia de mensagens.
- Avaliação da força da chave: Fraca, Média ou Forte.
- Limitação de mensagens a 128 caracteres.
- Preservação de espaços, números e pontuação.
- Validação de entradas e tratamento de erros.
- Interface interativa pelo terminal.

## Tecnologias

- **Python 3**
- **Biblioteca padrão `collections`**
- **GitHub Codespaces** para execução online.

## Como executar

Abra o repositório no GitHub Codespaces ou utilize um terminal com Python 3 instalado.

Execute:

`python3 criptografia.py`

O programa disponibiliza três opções: cifrar, decifrar ou sair.
